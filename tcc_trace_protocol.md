# TCC cycle trace ABI v1

KWP SID 0x21 RLI 0x2D, USB transport only. CAN request rejected. All integers little-endian. Old RLI 0x24 unchanged.

Request after SID: exactly 16 bytes: rli u8=0x2D at 0, version u8=1 at 1, flags u8=0 at 2, max_records u8=1..16 at 3, boot_id u64 at 4, cursor u32 at 12. boot_id=0/cursor=0 discovers current boot, starting oldest; otherwise boot must match. Cursor inclusive, including zero after sequence wrap when boot_id is nonzero. Invalid size/version/flags/count/boot rejected.

Positive response: KWP [0x61,0x2D], then 40-byte header, then count*72-byte records. Header offsets: magic "TCCT" 0; version u8=1 4; flags u8 bit0 cursor_overwritten 5; header_size u16=40 6; record_size u16=72 8; count u16 10; boot_id u64 12; first_seq u32 20; next_seq u32 24; oldest_seq u32 28; newest_next_seq u32 32; overwritten_total u32 36. Other header flags zero.

Record offsets (all little endian): seq u32 0; timestamp_us u64 4; dt_us u32 12; flags u32 16; path u8 20; profile u8 21; actual_gear u8 22; target_gear u8 23; state_before u8 24; state_after u8 25; target_before u8 26; target_after u8 27; prefill_flags_before u8 28; prefill_flags_after u8 29; prefill_cycles_before u8 30; prefill_cycles_after u8 31; engine_rpm_at_tcc u16 32; input_rpm_at_tcc u16 34; output_rpm_at_tcc u16 36; converted_torque_at_tcc i16 38; atf_c_at_tcc i16 40; pedal_at_tcc u8 42; selected_can_request_bits u8 43; signed_engine_minus_input_rpm i16 44; filtered_absolute_slip_rpm i16 46; slip_target_before_rpm u16 48; slip_target_after_rpm u16 50; command_before_atf_mbar u16 52; command_after_atf_mbar u16 54; pm_requested_mbar u16 56; pm_final_pwm_raw u16 58; filtered_model_pressure_centimbar i32 60; pm_path u8 64; pedal_smoothed_at_tcc u8 65; coast_raw_pedal u8 66; coast_engine_rpm u16 67; quality_flags u8 69; reserved zero bytes 70..71.

Quality flags: bit0 speed sample accepted; bit1 raw N2/N3/output signals valid; bit2 coast engine 100ms sample valid and within safety RPM; bit3 coast pedal 100ms sample valid. These are existing gearbox reads only. For skipped update quality fields are zero/unavailable; TCC input fields are zero/unavailable, and selected CAN request bits are the prior stored diagnostic value on normal skipped paths; slave/diagnostic-stop early-continue records have zero/unavailable. No skipped path performs a fresh CAN query. Path: 0 TCC update skipped; 1 full update; 2 TCC disabled/map init failure; 3 gearbox outer branch forced PM target zero (!speeds_valid OR non-forward actual gear, including P/N/R, while engine_rpm>100). pm_path: 0 not calculated; 1 normal output; 2 forced zero. Prefill flags bit0 running, bit1 done. Record flags: bit0 prefill branch taken; bit1 is_shifting; bit2 release_shifting; bit3 upshifting; bit4 was_shifting; bit5 exact TCC input snapshot valid; bit6 PM output valid; bit7 update skipped; bit8 CAN request freshness unknown; bit9 signed raw slip saturated (full difference reconstructable from engine/input u16); bit10 command pressure clamped to u16; bit11 filtered absolute slip saturated. Unknown bits and nonzero reserved rejected by host.

Nominal 50 Hz, actual monotonic microsecond timestamps and dt. One record per main gearbox cycle. TCC inputs are the exact values passed to update; PM output is captured later in that cycle. Pressure fields are nonnegative commands or an internal filtered model, never hydraulic measurements. pm_final_pwm_raw is the PWM duty command stored by the TCC solenoid after the final PressureManager update in the same main loop, not hydraulic pressure nor a measured electrical response. pm_requested_mbar is PressureManager target read at that same end-of-loop point; it can be an earlier retained target on update-skipped paths. Timestamp and dt are taken at cycle start. Physical ADC current measurement and PWM waveform are excluded because their sampling is asynchronous; the logical raw PWM duty request is included at the documented PM endpoint. Boot nonce is generated once in Gearbox construction, before the producer loop. Fixed 512-record ring (36864 bytes) plus bookkeeping; producer has no allocation or I/O. Reading is bounded, mutex protected, non-consuming, independent per reader. Sequence gaps and overwritten_total show lost records; sequence arithmetic modulo 2^32.
